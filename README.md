A 4 KB Python chess engine: a 0x88 board, alpha-beta search with quiescence and piece-square tables, playing the make.fun gauntlet through the env HTTP API. It searches to a fixed node budget, never a clock, so replays match.

## Run it

```sh
MAKEFUN_ENV_URL=http://127.0.0.1:8080 python3 main.py
```
